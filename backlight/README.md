# Подсветка козырька — электросхема

Одно гнездо USB-C питает всё: зарядку Kindle, Arduino Nano, энкодер и подсветку из COB-нитей. Энкодер через Nano крутит яркость — в v1 больше ничего, без HomeKit (решение 2026-10-19). Прошивка — `src/` (PlatformIO).

![Схема](schematic.svg)

## Что куда

| Откуда | Куда | Примечание |
| --- | --- | --- |
| USB-C `V` | шинка **+5V** | силовой провод |
| USB-C `G` | шинка **GND** | силовой провод |
| USB-C `D+` / `D−` | — | не подключать |
| C1 `+` / `−` | +5V / GND у самого входа | минус — сторона с полосой на корпусе |
| Kindle-кабель: красный (VBUS) | +5V | цвета прозвонить, бывают нестандартные |
| Kindle-кабель: чёрный (GND) | GND | |
| Kindle-кабель: зелёный (D+) + белый (D−) | **друг с другом**, заизолировать | иначе Kindle может решить, что это компьютер, и урезать ток заряда |
| Nano `5V` | +5V | **не VIN** (VIN идёт через стабилизатор, ему нужно ≥7 В) |
| Nano `GND` | GND | |
| Энкодер `+` / `GND` | Nano `5V` / `GND` | |
| Энкодер `CLK` | Nano `D2` | прерывание |
| Энкодер `DT` | Nano `D3` | прерывание |
| Энкодер `SW` | Nano `D4` | подтяжка в прошивке (`INPUT_PULLUP`) |
| Nano `D9` | R1 220 Ом → затвор Q1 (ножка 1) | ШИМ |
| R2 10 кОм | затвор Q1 ↔ +5V | держит лампу выключенной, пока Nano грузится или прошивается |
| Q1 исток (ножка 2) | +5V | |
| Q1 сток (ножка 3) | LAMP+ → R3 (R4, R5) 6,8 Ом 1 Вт | по резистору на каждую нить |
| R3 / R4 / R5 | «+» нити 1 / 2 / 3 | |
| «−» всех нитей | GND | |

Q1 = AO3401, P-канал, ключ по плюсу: `D9` LOW — свет, HIGH — темно.

## Развязка по питанию

- **Звезда от входа.** USB-C → короткими толстыми проводами на перфборд, там C1 и две шинки +5V / GND. От шинок — **отдельные пары** к Kindle, к Nano (энкодер питается от пинов Nano) и к лампе. Импульсный ток ШИМ лампы (до 0,9 А на трёх нитях) тогда не течёт по земле Nano и Kindle.
- **C1 1000 мкФ у входа** гасит импульсы ШИМ — Kindle и Nano не видят просадок.
- **C2 0,1 мкФ** параллельно C1 — высокочастотные помехи. Вторую 0,1 мкФ можно на пины `5V`–`GND` у Nano.
- **R1 220 Ом** в затвор — ограничивает бросок тока из пина и звон на фронтах.
- **R2 10 кОм** затвор → +5V — без неё при старте Nano пин висит в воздухе и лампа может вспыхнуть.
- Скачет энкодер — по 10 нФ с `CLK` и `DT` на GND (аппаратный антидребезг).
- Q1, C1 и резисторы R3–R5 — на перфборде в базе; к козырьку тянуть по «+» каждой нити (уже после её резистора) и один общий GND.
- Силовые линии (вход → шинки, Kindle, лампа) — 0,3–0,5 мм²; сигнальные — любым тонким.

## Ток и тепло

| Потребитель | Ток |
| --- | --- |
| Kindle (заряд) | ≤ ~0,5 А (оценка) |
| Nano + энкодер | ~0,03 А |
| COB-нить на 100 % | 0,3 А каждая |
| **Итого** | 1 нить ~0,85 А · 3 нити ~1,45 А — зарядки 5 В 2 А хватает |

Резистор: (5 − 3 В) / 0,3 А ≈ 6,7 → **6,8 Ом**; на 100 % греется на 0,6 Вт, поэтому 1 Вт. Нить на 100 % — ещё ~0,9 Вт тепла. Резисторы не прижимать к PETG.

## Прошивка Nano

- Код — `backlight/` (PlatformIO, PR #15). Залита в Nano 19.10, на стенде не проверена — #17.
- Энкодер — библиотека `Encoder` (Paul Stoffregen) на прерываниях D2/D3.
- Поворот — шаг яркости по гамма-кривой (внизу шаги мельче, глаз видит ровно).
- Клик `D4` — вкл/выкл с памятью уровня, плавное нарастание.
- ШИМ на `D9` — Timer1, Fast PWM 10 бит, ~15,6 кГц (не мерцает на камеру, не пищит), инверсный режим (P-канал).
- Выкл — ШИМ отключить и держать `D9` в HIGH (иначе инверсный ШИМ оставляет импульс в 1 такт и нить тлеет).
- Уровень — в EEPROM через ~5 с после последнего поворота: переживает отключение питания и не изнашивает EEPROM.
- ⚠️ Прошивать Nano через её mini-USB **только при воткнутом основном USB-C**. Иначе мак питает через диод Nano всю шину вместе с Kindle и лампой.

## Проверить до пайки

- [ ] USB-C платка — гнездо, не штекер; кабель C→C от зарядки → на `V`–`G` 5 В
- [ ] Kindle-кабель — прозвонить жилы до пинов micro-USB (1 VBUS, 2 D−, 3 D+, 5 GND), жил 4
- [ ] Полярность нити: 5 В → 220 Ом → нить; тлеет — правильно (обратная полярность через резистор не вредит)
- [ ] AO3401 прозвонкой диода: красный щуп на ножку 3 (сток), чёрный на 2 (исток) → ~0,6–0,7 В
- [ ] Энкодер: между `+` и `CLK` / `DT` ~10 кОм (подтяжки на плате есть)
- [ ] После сборки: ток одной нити на 100 % — 0,25–0,3 А (мультиметр в разрыв); больше — поставить 8,2 Ом
- [ ] Kindle на шине заряжается: `ssh kindle 'gasgauge-info -c'` держится или растёт

## Не решено

- Сколько нитей — 1, 2 или 3. На схеме разницы нет: каждая следующая — ещё одна пара «резистор + нить» между LAMP+ и GND.
- Где на корпусе энкодер.
