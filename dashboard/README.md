# Дашборд Kindle-календаря — фінальний дизайн (обрано 2026-08-26)

Обраний варіант: **«Веб-інтерфейс»** (product-UI, картки) — фінал відбору з
чотирьох напрямів (передовиця / швейцарський плакат / термінал / веб).
Дизайн-рішення: Onest + JetBrains Mono (повна укр. кирилиця), картки 1px
#c2c2c2 radius 12 без тіней, лінія поточного часу в агенді (à la Google
Calendar), GSC як stat-плитки зі спарклайнами (історія #999, поточна точка
#000). Екран 800×600 landscape → на панель іде портрет 600×800.

## Файли

- `template.html` — єдине джерело правди дизайну. ЖИВЕ на момент рендера
  (JS): дата, «оновлено», мітка лінії часу, міні-місяць. МОК (позначено
  коментарями): події, погода, GSC.
- `render.sh` — headless Chrome → поворот (ROTATE=90|270) → grayscale →
  `out/dash.png` (600×800, Gray).
- `push-to-kindle.sh` — заливка на книгу по SSH (`cat >`, scp там немає) +
  `eips -f -g`. Джерело для 15-хв циклу kindle-dash:
  `/mnt/us/dashboard/local/screen.png`.

## Оновити екран вручну

```
./render.sh && ./push-to-kindle.sh
```

## Наступна фаза (дані)

Рендер переїжджає на NAS (192.168.0.133): той самий template.html, але
блоки-моки заповнюються реальними даними перед скріншотом:

- події — приватний iCal-URL Google Calendar (5 днів);
- погода — Open-Meteo (безкоштовно, без ключа);
- GSC — Search Console API (кліки 7 днів по slotranker / calc-fleet /
  esportsbet), креденшели через 1Password SA;
- push-модель за рішенням із заміток: NAS рендерить → заливає по SSH →
  смикає eips; мін. інтервал 10–30 с + дебаунс, щогодини повний refresh
  («пульс» проти ghosting).
